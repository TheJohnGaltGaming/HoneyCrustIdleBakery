# HoneyCrustIdleBakery

A cozy bakery idle game you can play in the browser. Tap the oven, hire bakers, buy upgrades, and earn Recipe Stars for a permanent boost. Progress is saved on your device, and it works on a phone.

**Play:** https://thejohngaltgaming.github.io/HoneyCrustIdleBakery/

Pages is not on yet. In the repository settings, set Pages to deploy from the `main` branch, folder `/`.
