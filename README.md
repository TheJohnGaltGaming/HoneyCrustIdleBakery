# HoneyCrustIdleBakery

A cozy bakery idle game you can play in the browser. The shop is an overhead bakery scene: tap objects to upgrade them, hire staff, dress them in outfits, switch decor looks, and move the bakery to a new location. Progress is saved on your device, and it works on a phone.

**Play:** https://thejohngaltgaming.github.io/HoneyCrustIdleBakery/
